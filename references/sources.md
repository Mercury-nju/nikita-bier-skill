## S04 — Two Network-Product Test Strategies, 2025-05-01

- [Original post](https://x.com/nikitabier/status/1917931582670733394)
- Checked: a retained local harvested record contains the post text. Direct X access did not expose the text during this review; treat this as local-record support.
